# Epson-config

โปรแกรมหน้าต่างภาษาไทย (ดีไซน์กระจกใส ธีมสว่าง/มืดตาม Windows) สำหรับเช็กสถานะและ **รีเซ็ตตัวนับซับหมึก (waste ink pad counter)** ของเครื่องพิมพ์ Epson ผ่านสาย USB หรือ Wi‑Fi กดใช้ได้เลย ไม่ต้องพิมพ์คำสั่ง

## ทำอะไรได้บ้าง (v3)

| หน้า | ใช้ทำอะไร |
|---|---|
| **ภาพรวม** | เช็กสถานะ ซับหมึกกี่ % ระดับหมึกแต่ละสี รีเซ็ตซับหมึก และ **รีเซ็ตชั่วคราว** สำหรับรุ่นใหม่ที่ล็อก EEPROM |
| **สถิติเครื่อง** | จำนวนหน้าที่พิมพ์ทั้งหมด จำนวนครั้งล้างหัวพิมพ์ จำนวนครั้งเติม/เปลี่ยนหมึกแต่ละสี วันที่เริ่มใช้งาน (อ่านอย่างเดียว) |
| **บำรุงรักษา** | พิมพ์หน้าเช็กหัวพิมพ์ ล้างหัวพิมพ์ ล้างแบบเข้ม และตั้งเวลาปิดเครื่องอัตโนมัติ (Power Off Timer) |
| **ประวัติและสำรอง** | ประวัติว่ารีเซ็ตเมื่อไหร่ เครื่องไหน คำแนะนำว่าควรเปลี่ยนแผ่นซับหรือยัง และปุ่ม **กู้คืน** ค่า EEPROM จากไฟล์สำรอง |
| **รุ่นที่รองรับ** | รายชื่อรุ่นทั้งหมดในฐานข้อมูล พร้อมช่องค้นหา และบอกว่ารุ่นไหนดูสถิติ/ตั้งเวลาปิดได้ |
| **ตั้งค่า** | ตั้งเกณฑ์แจ้งเตือนหมึกใกล้หมด ตรวจหาอัปเดต และดูรายละเอียดทางเทคนิค |

ด้านบนเลือกการเชื่อมต่อได้ **USB** หรือ **Wi‑Fi** (ใส่ IP เองหรือกด **ค้นหา** เพื่อหาเครื่องพิมพ์ในวงแลนอัตโนมัติ)

ทดสอบกับเครื่องจริงแล้ว: **Epson L4260** (เฟิร์มแวร์ XJ05Q2) รุ่นอื่นที่อยู่ในฐานข้อมูลของ ReInkPy น่าจะใช้ได้ แต่ยังไม่ได้ทดสอบ

## ดาวน์โหลด

**[⬇ EpsonInkPadReset.exe (เวอร์ชันล่าสุด)](https://github.com/Mark-Notify/Epson-config/releases/latest/download/EpsonInkPadReset.exe)** · Windows 10/11 64-bit · ไม่ต้องลง Python

ดูทุกเวอร์ชันและ SHA-256 ได้ที่หน้า [Releases](https://github.com/Mark-Notify/Epson-config/releases)

โปรแกรมเช็กอัปเดตเองตอนเปิด ถ้ามีเวอร์ชันใหม่จะขึ้นแถบสีน้ำเงินด้านบน กด **อัปเดตเลย** แล้วโปรแกรมจะโหลด ตรวจ SHA-256 ปิดตัวเอง และเปิดเวอร์ชันใหม่ให้ (กด **ตรวจหาอัปเดต** ที่มุมล่างซ้ายเพื่อเช็กเองก็ได้)

ไฟล์ไม่ได้เซ็นชื่อดิจิทัล ตอนเปิดครั้งแรก Windows อาจขึ้น "Windows protected your PC" ให้กด **More info** แล้ว **Run anyway**

## วิธีใช้ (ผู้ใช้ทั่วไป)

1. เสียบสาย USB ระหว่างคอมกับเครื่องพิมพ์ แล้วเปิดเครื่องพิมพ์
2. ดับเบิลคลิก `EpsonInkPadReset.exe`
3. กด **ตรวจสอบเครื่องพิมพ์** โปรแกรมจะบอกรุ่น สถานะ ซับหมึกเต็มหรือยัง และระดับหมึกแต่ละสี
4. ถ้าซับหมึกเต็ม ปุ่มจะเปลี่ยนเป็นสีแดง **รีเซ็ตซับหมึก** กดแล้วติ๊ก "ฉันเข้าใจ" แล้วกด **รีเซ็ตเลย**
5. ปิดเครื่องพิมพ์ด้วยปุ่ม Power รอไฟดับ แล้วเปิดใหม่ จากนั้นกด **ตรวจสอบเครื่องพิมพ์** อีกครั้งเพื่อยืนยัน

ก่อนรีเซ็ต กู้คืน หรือเปลี่ยนเวลาปิดเครื่อง โปรแกรมจะสำรองข้อมูล EEPROM ของเครื่องพิมพ์ไว้ที่ `Documents\EpsonResetBackups` อัตโนมัติ ถ้าสำรองไม่สำเร็จจะไม่ทำต่อ ประวัติการทำงาน (`history.json`) และการตั้งค่า (`settings.json`) อยู่ในโฟลเดอร์เดียวกัน

### กู้คืนจากไฟล์สำรอง

ถ้ารีเซ็ตแล้วเครื่องมีอาการแปลก ไปที่ **ประวัติและสำรอง** กด **กู้คืน** ที่ไฟล์ที่ต้องการ โปรแกรมจะเทียบไฟล์กับค่าในเครื่องแล้วแสดงตำแหน่งที่ต่างกันก่อน จะเขียนกลับเฉพาะตำแหน่งที่ต่าง และจะไม่ยอมกู้คืนไฟล์ของรุ่นหรือซีเรียลอื่น ก่อนเขียนจะสำรองค่าปัจจุบันไว้อีกไฟล์ จึงย้อนกลับได้

### Wi‑Fi และรีเซ็ตชั่วคราว

- รุ่นเก่าหลายรุ่นรีเซ็ตผ่าน Wi‑Fi ได้เหมือน USB (ใช้ SNMP)
- รุ่นใหม่ที่ปิดการเข้าถึง EEPROM (เช่น L3250 และ L4260 ผ่าน Wi‑Fi) ใช้ **รีเซ็ตชั่วคราว** ได้ ปุ่มนี้ปลดล็อกให้พิมพ์ต่อได้อีกระยะหนึ่งโดยไม่ล้างตัวนับ เครื่องจะหยุดอีกในภายหลังและทำซ้ำได้

### เช็กหัวพิมพ์และล้างหัวพิมพ์

ผ่าน USB โปรแกรมส่งคำสั่งทางคิวพิมพ์ของ Windows จึงต้องติดตั้งไดรเวอร์ Epson ไว้ก่อน (เลือกคิวเองได้ในหน้าบำรุงรักษา) ผ่าน Wi‑Fi ส่งตรงไปที่เครื่องพิมพ์ การล้างหัวพิมพ์ทำให้หมึกเสียไหลลงแผ่นซับ ตัวนับซับหมึกจึงเพิ่มขึ้น

## ข้อควรรู้

- **แผ่นซับหมึกจริงยังเต็มอยู่** การรีเซ็ตแค่ทำให้ตัวนับกลับเป็นศูนย์ ควรล้างหรือเปลี่ยนแผ่นซับ หรือต่อถังหมึกทิ้งภายนอก ไม่งั้นหมึกจะล้นออกใต้เครื่อง
- ห้ามปิดเครื่องพิมพ์หรือถอดสายระหว่างรีเซ็ต
- การแก้ EEPROM อาจทำให้เสียสิทธิ์ประกันจาก Epson ถ้าเครื่องยังอยู่ในประกัน ส่งศูนย์ดีกว่า
- รุ่นใหม่หลายรุ่น (รวม L4260) ปิดการเข้าถึง EEPROM ผ่าน Wi‑Fi ให้ใช้สาย USB หรือรีเซ็ตชั่วคราว
- ฟีเจอร์ที่ทดสอบกับเครื่องจริงแล้วคือเช็กสถานะและรีเซ็ตผ่าน USB บน L4260 ฟีเจอร์ใหม่ใน v3 (สถิติ กู้คืน ตั้งเวลาปิด Wi‑Fi เช็ก/ล้างหัวพิมพ์) ทดสอบกับเครื่องพิมพ์จำลองแล้ว แต่ยังไม่ได้ทดสอบกับเครื่องจริง
- หน้าต่างใหม่ใช้ Microsoft Edge WebView2 (มีใน Windows 11 และ Windows 10 ส่วนใหญ่) ถ้าเครื่องไม่มี โปรแกรมจะเปิดหน้าต่างแบบเดิมให้อัตโนมัติ (บังคับหน้าต่างแบบเดิมได้ด้วย `EpsonInkPadReset.exe --classic`)
- ปิดโปรแกรมอื่นที่คุยกับเครื่องพิมพ์ (เช่น Epson Status Monitor, WIC Reset) ก่อนใช้

## Build เป็น .exe (สำหรับนักพัฒนา)

ต้องมี Python 3.10+ (คำสั่ง `py`), git และ curl (มากับ Windows 10/11)

```bat
build.bat
```

สคริปต์จะ:

1. โหลด [epson_print_conf](https://github.com/Ircama/epson_print_conf) เวอร์ชันที่ล็อกไว้ลง `vendor\`
2. สร้าง venv และติดตั้ง dependency กับ PyInstaller
3. โหลด `epson.toml` ของ [ReInkPy](https://codeberg.org/atufi/reinkpy) แล้วแปลงเป็น `printers.pickle`
4. Build ได้ไฟล์ `dist\EpsonInkPadReset.exe` (ไฟล์เดียว ไม่ต้องลง Python บนเครื่องที่ใช้)

รันจากซอร์สโดยไม่ build (หลังรัน `build.bat` ครั้งแรกแล้ว):

```bat
venv\Scripts\python app_web.py
```

หน้าตา (HTML/CSS/JS) อยู่ในโฟลเดอร์ `ui\` ส่วน `app_web.py` เป็นสะพานระหว่างหน้าเว็บกับ `epson_reset_core.py` และ `epson_reset_gui.py` คือหน้าต่างแบบเดิม (สำรองไว้กรณีไม่มี WebView2)

ทดสอบโดยไม่มีเครื่องพิมพ์ (เครื่องพิมพ์จำลอง L4260):

```bat
set EPSON_RESET_MOCK=1
venv\Scripts\python app_web.py
```

## ออกเวอร์ชันใหม่

GitHub Actions ([build.yml](.github/workflows/build.yml)) build .exe บน Windows ให้ทุกครั้งที่ push ขึ้น `main` (โหลดได้จากแท็บ Actions) ถ้าจะปล่อยให้ผู้ใช้อัปเดต:

1. แก้ `APP_VERSION` ใน `epson_reset_core.py` เช่น `"2.2.0"`
2. commit แล้วติด tag ให้ตรงกัน: `git tag v2.2.0` แล้ว `git push origin main v2.2.0`
3. Actions จะ build และสร้าง Release พร้อม `EpsonInkPadReset.exe` กับ `.sha256` ผู้ใช้ทุกคนจะเห็นแถบอัปเดตตอนเปิดโปรแกรมครั้งถัดไป

ถ้าเลข tag ไม่ตรงกับ `APP_VERSION` Actions จะหยุดและไม่สร้าง Release

## เครดิตและสัญญาอนุญาต

- หน้าต่างหลักใช้ [pywebview](https://github.com/r0x0r/pywebview) (BSD-3) หน้าต่างแบบเดิมใช้ [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) (MIT)
- เช็ก/ล้างหัวพิมพ์ใช้ [epson_escp2](https://pypi.org/project/epson-escp2/) สร้างคำสั่ง ESC/P2
- [epson_print_conf](https://github.com/Ircama/epson_print_conf) โดย Ircama, สัญญาอนุญาต EUPL-1.2 ใช้คุยกับเครื่องพิมพ์ผ่าน USB และเขียน EEPROM
- ข้อมูลรุ่นเครื่องพิมพ์จาก `epson.toml` ของ [ReInkPy](https://codeberg.org/atufi/reinkpy)

repo นี้ไม่ได้รวมซอร์สของสองโปรเจกต์ข้างต้นไว้ `build.bat` โหลดมาตอน build แต่ไฟล์ .exe ในหน้า Releases มีโค้ดของ epson_print_conf (EUPL-1.2) อยู่ข้างใน build จาก commit `2dc3bebacf314f22bd6484acdb2a7434c7cc00ad` ซอร์สฉบับเต็มดูได้ที่ https://github.com/Ircama/epson_print_conf/tree/2dc3bebacf314f22bd6484acdb2a7434c7cc00ad
